## 🚀 How to Run the Projects

Each folder is self-contained. Navigate to any project folder and open `index.html` in your favorite web browser:

```bash
# Clone the complete internship repository
git clone https://github.com/Moonligh226/OIBSIP.git

# Navigate to Temperature Converter
cd OIBSIP/WebDev-L1-TemperatureConverter
```

For the portfolio project with Vite and GSAP:
```bash
cd OIBSIP/WebDev-L1-PersonnalPortfolio
npm install
npm run dev
```
